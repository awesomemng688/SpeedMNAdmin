# Fix Hilt Kotlin Metadata Version Mismatch

The project is experiencing a build error where Hilt's annotation processor cannot read the Kotlin metadata generated by Kotlin 2.2.10. This is because the version of Hilt currently in use (2.51) bundles an older version of the `kotlinx-metadata-jvm` library that only supports up to Metadata version 2.0.0.

## User Review Required

> [!IMPORTANT]
> I am proposing an upgrade to Hilt 2.60.1. This is a significant version jump from 2.51. While generally backward compatible, please ensure your project doesn't rely on any deprecated Hilt internals.

## Proposed Changes

### Build Configuration

#### [MODIFY] [libs.versions.toml](file:///C:/Users/Awesome/AndroidStudioProjects/SpeedMNAdmin/gradle/libs.versions.toml)
- Update `hilt` version to `2.60.1`.
- Add `kotlin-metadata-jvm` library to the `[libraries]` section, matching the Kotlin version (2.2.10).

#### [MODIFY] [app/build.gradle.kts](file:///C:/Users/Awesome/AndroidStudioProjects/SpeedMNAdmin/app/build.gradle.kts)
- Add `kapt(libs.kotlin.metadata.jvm)` to the dependencies to explicitly provide the newer metadata library to the Hilt annotation processor.

## Verification Plan
